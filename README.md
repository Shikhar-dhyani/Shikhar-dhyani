## 🤖 Featured project — Riyu

> **Stack:** LangGraph · FastAPI · Azure · Redis · Qdrant · React · Socket.IO · Docker

A production-grade multi-agent analytics platform that lets users query business data in natural language — with real intelligence behind it.

**Architecture highlights:**
- **8-agent orchestration** — Supervisor, SQL, Data Source, Harmonization, Multilingual, Data Scientist, Visualizer, Technical Writer — coordinated via LangGraph StateGraph with a custom A2A protocol over FastAPI microservices
- **LLM-driven planning** — Supervisor performs intent classification, dynamic plan decomposition, per-step agent assignment, query rewriting, and cancellation-aware execution
- **Redis-backed sandbox pool** — per-tier pre-warmed ACI containers with isolated Python sandboxes, SIGALRM timeouts, and 3-loop LLM feedback retries
- **EDA + RAG pipeline** — per-column profiling streams interactive clarifying questions via Socket.IO, then indexes semantic metadata + suggested queries into Qdrant for context injection
- **PDF reporting** — Playwright renders ECharts to pixel-perfect PDF reports on Azure Blob
- **Tier/pricing engine** — per-tier per-agent LLM overrides, credit accounting with deficit carry-forward, full Admin Panel, Incognito Mode, and Microsoft OIDC + Google OAuth2
