## 💡 Featured Project

### 🤖 AI-Powered Data Analysis Chatbot @ ClicFlyer
> **Technologies:** Azure CLU • Claude API • LangGraph • SQL Server • WebSocket

A production-grade natural language analytics engine enabling non-technical users to query business data conversationally.

**Key Contributions:**
- **LangGraph Orchestration** — Architected a LLM-powered planner that decomposes complex user queries into dependency-aware DAGs of subtasks, enabling parallel execution with intelligent conditional routing and comprehensive error recovery across 7 workflow nodes
- **Dual-LLM Architecture** — Integrated Azure Cognitive Language Understanding (CLU) for multi-intent classification and entity extraction, with automatic failover between Azure Anthropic Foundry and backup models
- **Context Propagation** — Designed a system where dependent subtasks receive upstream execution results as parent context, enabling Claude to generate contextually-aware SQL with proper joins, filters, and aggregations
- **Real-Time Streaming** — Built WebSocket streaming with emission queue management for progressive task updates, including cancellation-aware execution, session-based registry, and checkpoint-based history persistence to Azure Blob Storage
- **Scope Validation** — Engineered a temporary table architecture for data scope validation and autocomplete extraction

**Impact:** Delivered natural language analytics for non-technical business users with intelligent query decomposition and real-time streaming results.
